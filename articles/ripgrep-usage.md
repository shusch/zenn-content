この記事では ripgrep (rg) の基本的な使用法と、主なオプションについて記載します。
すべてのオプションを網羅して解説するようなものではありません。

## 基本構文

ripgrep (rg) コマンドはデフォルトで正規表現パターンを解釈し、ディレクトリを再帰的に検索します。
grep コマンドでは `-r` オプションが必要ですが、ripgrep は再帰検索がデフォルトで有効になっています。

また .gitignore に記載されたファイルと、隠しファイルおよびバイナリファイルを自動的に検索対象から除外します。

**書式**

```sh
rg [OPTIONS] PATTERN [PATH...]
```

PATH を指定しない場合は、カレントディレクトリに対して検索を行います。

```sh
# カレントディレクトリ以下の foo を検索する
rg 'foo'
```

PATH を指定すると、指定したファイル・ディレクトリに対して検索を行います。

```sh
# 検索対象のパスを指定することもできる
rg 'foo' ./directory
```

## 検索パターンを正規表現ではない通常の文字列とみなす (-F)

パターン全体を正規表現ではなく通常の文字列として解釈します。

このオプションを使用すると、`.(){}*+` などのメタ文字をエスケープする必要がありません。

```sh
rg -F '$foo'
```

## 大文字と小文字 (-i, -S)

デフォルトでは大文字と小文字は区別して検索します。
別の挙動とするにはオプションを指定します。

**大文字と小文字を区別しない**

```sh
rg -i 'Foo'
```

**パターンに大文字が含まれていれば区別し、すべて小文字なら区別しない**

```sh
# 区別されない
rg -S 'foo'

# 区別される
rg -S 'Foo'
```

## 隠しファイルと隠しディレクトリを検索対象にする (-.)

隠しファイルと隠しディレクトリを検索対象にします。
ただし、明示的に隠しファイルやディレクトリを検索対象として引数に指定された場合、このオプションが指定されていなくとも検索対象となります。

なお、このオプションを指定すると .git ディレクトリなども検索対象となるため、必要に応じて別途除外します。

```sh
rg -. 'foo'

# .git は除外したい場合
rg -. -g '!.git' 'pattern'
```

## glob で検索対象を絞り込む・除外する (-g)

検索対象のファイルを glob で限定、または除外できます。
glob とは、ワイルドカードでファイル名やパスを指定する記法です。

glob の規則は .gitignore の規則に準じます。

先頭に `!` を付けると、一致するファイル・ディレクトリは除外されます。

```sh
# foo ディレクトリ配下すべてを対象
rg -g 'foo/**' 'pattern'

# 階層を問わず foo という名前のファイル・ディレクトリを除外
rg -g '!foo' 'pattern'

# 階層を問わず *_test.txt ファイルを除外
rg -g '!*_test.txt' 'pattern'

# -g オプションは複数指定できる
rg -g '!foo' -g '!*_test.txt' 'pattern'
```

## 一致する行を除外する (-v)

検索パターンに一致する行を除外し、一致**しない**行を出力します。

```sh
# foo に一致する行を除外する
rg -v 'foo'
```

## .gitignore などを考慮しない (--no-ignore)

.gitignore などに記載されたファイルを無視せず、検索対象としたい場合に指定します。

```sh
rg --no-ignore 'foo'
```

## 検索パターンを複数指定する (-e)

検索パターンを複数指定し、OR 条件として検索します。

```sh
# foo または bar に一致する行を出力
rg -e 'foo' -e 'bar'
```

## デフォルトの除外フィルタを緩める (-u, -uu, -uuu)

ripgrep はデフォルトで各種ファイルを検索対象から除外しますが、この自動フィルタリングを段階的に緩めます。

```sh
# --no-ignore と等価
# ignore ファイルを考慮しない
rg -u 'foo'

# --no-ignore -. と等価
# 隠しファイルも検索対象とする
rg -uu 'foo'

# --no-ignore -. --binary と等価
# バイナリも検索対象とする
rg -uuu 'foo'
```

## 検索対象となるファイルを確認する (--files)

実際に検索を行わず、検索対象となるファイルの一覧を出力します。

引数の検索パターンは取らず、その他のオプションと、パス引数のみ指定可能です。

```sh
rg --files

# パスを指定
rg --files ./directory

# 検索対象を指定する
rg -. -g '!.git' --files

# 検索対象の結果をファイル名で絞り込む
rg --files | rg 'foo'
```

## UTF-8, UTF-16 (BOM) 以外のファイルで検索する (-E)

UTF-8, UTF-16 (BOM) 以外のファイルで正しく検索をしたい場合に指定します。

```sh
# Shift_JIS のファイルを検索する
rg -E shift_jis 'foo'
```
